# Parking Management System API (PHP + MySQL)

A RESTful API for managing parking slots in a multi-level parking system using PHP and MySQL.

## Features:

- Add new parking slots
- View all parking slots
- View single slot by ID
- Update parking slot information
- Delete parking slots
- Uses **foreign key** support-ready structure
